# Changelog

## [Unreleased]

### Changed

- Favo Smoke and Favo Veil, and the gray in the app palette, are less sandy: the gray keeps half as much of the honey tint, so it reads as a calm neutral with only a hint of warmth.

## [0.2.0] - 2026-11-06

### Added

- A palette for websites and apps, with a calm gray, twelve steps for every Favo color and ready-to-use CSS, Tailwind and JSON files. See APPS.md.
- Favo Smoke and Favo Veil, calmer dark and light variants with every code color on a warm gray, for every port: Neovim, Vim, VS Code, Cursor, Zed, Ghostty, OpenCode, T3 Code and Herdr.

## [0.1.1] - 2026-11-02

### Added

- Every release now comes with a `.vsix` file on GitHub, so you can install Favo in VS Code or Cursor without waiting for a store.

### Changed

- The VS Code Marketplace and Open VSX pages now link to this project and its issues.

## [0.1.0] - 2026-11-02

### Added

- Favo Honey and Favo Wax for VS Code and Cursor, with language server highlighting, rainbow brackets, diffs, the terminal and the whole interface.
- Favo Honey and Favo Wax for Neovim, Vim, Zed, Ghostty, OpenCode, T3 Code and Herdr.
