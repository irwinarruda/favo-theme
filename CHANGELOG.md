# Changelog

## [Unreleased]

## [0.1.1] - 2026-11-02

### Added

- Every release now comes with a `.vsix` file on GitHub, so you can install Favo in VS Code or Cursor without waiting for a store.

### Changed

- The VS Code Marketplace and Open VSX pages now link to this project and its issues.

## [0.1.0] - 2026-11-02

### Added

- Favo Honey and Favo Wax for VS Code and Cursor, with language server highlighting, rainbow brackets, diffs, the terminal and the whole interface.
- Favo Honey and Favo Wax for Neovim, Vim, Zed, Ghostty, OpenCode, T3 Code and Herdr.
